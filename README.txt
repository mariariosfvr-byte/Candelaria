# La Candelaria — Landing page

Landing page responsive en HTML, CSS y JavaScript vanilla.

## Cómo usar
1. Descomprime el archivo.
2. Abre `index.html` en tu navegador.
3. Para publicarla, sube `index.html` a la raíz de un repositorio de GitHub y activa GitHub Pages.

## Personalización antes de publicar
- Las fotografías son imágenes remotas de Unsplash y requieren conexión a internet.
- Sustituye las fotografías por imágenes propias de La Candelaria con sus créditos correspondientes.
- El asistente es una demostración de interfaz; no está conectado a un modelo de IA.
- El mapa, el reconocimiento visual y el archivo cultural se presentan como funcionalidades propuestas, no como servicios ya implementados.
- Verifica los datos y permisos de uso de cada obra antes de publicar contenido real.
